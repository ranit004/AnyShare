Design a sleek, modern, and visually engaging landing page for a file-sharing platform called 'AnyShare.' The landing page should feature a cutting-edge UI with smooth animations, micro-interactions, and a conversion-focused layout. The style should be minimalistic yet highly functional, ensuring an intuitive user experience."

1️⃣ Layout & Structure (Responsive & Scalable UI)
Define the landing page sections and layout.

📌 Prompt Example:
*"The landing page should be fully responsive and structured in a modern, clean, and minimalistic layout with the following sections:

Header: A sticky, transparent navbar with a subtle fade-in effect and animated hover states.
Hero Section: A bold headline, subtext, and a file upload UI with a smooth hover animation. The drop-zone box should have a soft-glow effect on hover and a drag-and-drop animation when a user uploads a file.
Features Section: Animated icons with a fade-in and scale-up effect as they come into view.
How It Works Section: Step-by-step cards with horizontal scrolling animation.
Testimonials Section: A carousel slider with smooth transitions showcasing user reviews.
Call-to-Action (CTA): A high-contrast, prominent "Upload Now" button with a hover-scale effect.
Footer: Minimalistic footer with social icons, quick links, and a *subtle fade-in on scroll."
2️⃣ Color Palette & Typography (Elegant & Readable)
Define the aesthetic style and readability elements.

📌 Prompt Example:
*"Use a modern color palette with a focus on:

Dark Mode: Deep navy, black, with neon blue/purple accents.
Light Mode: Soft whites with pastel gradients.
Typography should be clean and elegant, using SF Pro, Inter, or Poppins for clear readability. Headings should have a bold weight (700), while body text should maintain a smooth 400–500 weight range."*

3️⃣ Animations & Micro-Interactions (High-Quality UI/UX)
Make the page interactive with smooth animations.

📌 Prompt Example:
*"The landing page should feature smooth, high-performance animations powered by Framer Motion, GSAP, or Lottie.

Hero Section Animations:
Text Fade-In: The heading and subtext should appear with a slight delay, fading in with a soft motion.
File Drop Animation: When a file is uploaded, a progress bar smoothly fills with a bouncing effect.
Scroll-Based Interactions:
Feature Cards: As users scroll, cards should appear one by one with a slide-up effect.
Parallax Backgrounds: Background images should subtly shift based on scroll position.
Button Hover Effects:
CTA Buttons: On hover, buttons should have a gentle scale-up (105%) and glowing effect.
Upload Icon: The upload icon should pulse every 5 seconds to draw attention."*
4️⃣ Performance & Development Optimization
Ensure smooth performance and developer-friendly assets.

📌 Prompt Example:
*"All animations should be optimized for performance:

Use Lottie JSON for lightweight vector animations instead of GIFs.
Lazy load images and animations to improve page speed.
GSAP & Framer Motion for high-performance, smooth transitions.
The landing page should be fully responsive using a 12-column grid system, and assets should be optimized for quick rendering."*

📌 Final Deliverables
✅ Figma/Framer design file with a fully interactive prototype.
✅ Animated hero section, feature cards, and smooth page transitions.
✅ Lottie JSON files for lightweight motion effects.
✅ CSS & JS-based animations using GSAP/Framer for seamless UX
